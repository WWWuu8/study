

> **send_exact() 解决的是“发送不完整”。**
>
> **它没有解决“消息边界在哪里”。**
>
> 而“粘包 / 拆包”的根本问题，就是：**TCP 根本不知道你的一次 send() 就是一条完整消息。**

------

# 一、先把“粘包、拆包”彻底想明白

你现在可能脑子里有一个误区：

```
客户端：

send("hello")
send("world")

             ↓

服务端：

recv() → "hello"
recv() → "world"
```

你会很自然地觉得应该这样。

但是 TCP 实际上不是这样工作的。

TCP 看见的不是：

```
[hello] [world]
```

而是一个连续的字节流：

```
h e l l o w o r l d
```

所以服务端：

```
recv()
```

可能拿到：

```
"helloworld"
```

这叫：

```
粘包
```

也可能：

```
第一次 recv() → "he"
第二次 recv() → "lloworld"
```

这叫：

```
拆包
```

甚至可能：

```
第一次 recv() → "hello"
第二次 recv() → "wo"
第三次 recv() → "rld"
```

这些都完全合法。

------

# 二、为什么 TCP 会这样？

把 TCP 想象成一条**传送带**。

客户端往传送带上放：

```
[消息1] [消息2] [消息3]
```

TCP 不关心：

```
消息1在哪里结束
消息2在哪里开始
```

它只知道：

```
字节1 → 字节2 → 字节3 → 字节4 → ...
```

所以服务端拿到的时候可能是：

```
      TCP字节流

-----------------------------
h e l l o w o r l d
-----------------------------
   ↑
recv 从这里拿一部分
```

也就是说：

> **TCP 负责“字节可靠、有序地到达”。**
>
> **TCP 不负责“消息一条一条地到达”。**

这句话你一定要记住。

------

# 三、那我们到底应该怎么办？

答案就是：

> **自己给消息规定“边界”。**

也就是你必须告诉服务端：

```
这一条消息到底有多长？
```

常见有 3 种办法：

### 方法1：固定长度

例如规定：

```
每条消息必须 100 字节
```

那么：

```
第1条 = 100字节
第2条 = 100字节
第3条 = 100字节
```

这个简单，但是浪费空间。

------

### 方法2：特殊结束符

例如规定：

```
消息结尾一定有 \n
```

于是：

```
hello\n
world\n
abc\n
```

服务端一直收，看到 `\n` 就知道：

```
一条消息结束了
```

这个方法也很好理解。

------

### 方法3：长度 + 数据

这是我最推荐你现在学习的方法。

每条消息变成：

```
[消息长度][真正的数据]
```

比如：

```
hello
```

有 5 个字节。

那么发送：

```
[5][hello]
```

再发送：

```
world
```

就是：

```
[5][hello][5][world]
```

服务端看到：

```
先读 4 个字节 → 得到长度 5

再读 5 个字节 → 得到 hello
```

然后：

```
再读 4 个字节 → 得到长度 5

再读 5 个字节 → 得到 world
```

这样无论 TCP 怎么拆：

```
[5][hel]
[lo][5][wor]
[ld]
```

我们都能重新拼回：

```
5 + hello
5 + world
```

这就是真正解决问题了。

# 四、你的 `recv_exact()` 终于有用武之地了

你自己已经写了这个：

```
int recv_exact(SOCKET s, char* buf, int n)
```

这个函数的作用就是：

> **无论 TCP 拆成几次，我一定要收到 n 个字节才算结束。**

例如：

```
recv_exact(cfd, buf, 4);
```

意思不是：

> “帮我随便收一点”。

而是：

> “我要整整 4 个字节。”

假设 TCP 实际情况是：

```
第一次 recv → 2字节
第二次 recv → 2字节
```

你的 `recv_exact()` 会自动变成：

```
2 + 2 = 4
```

最终拿到完整的 4 字节。

这就是它为什么特别适合处理：

```
[长度]
```

# 五、我们设计一个最简单的通信协议

你现在的程序规定：

```
每条消息：

前4字节 = 消息长度
后面 = 消息内容
```

所以：

```
客户端发送：

+----------------+-------------------+
| 4字节消息长度  | 真正的消息内容    |
+----------------+-------------------+
        ↑
      固定4字节
```

例如输入：

```
hello
```

实际发送：

```
+----------+-------+
|    5     | hello |
+----------+-------+
   4字节     5字节
```

注意：

```
5
```

不是字符 `'5'`。

而是一个真正的：

```
uint32_t
```

也就是 4 字节整数。

# 六、为什么还要 `htonl()`？

因为网络传输规定使用：

```
网络字节序 = 大端
```

所以：

客户端：

```
uint32_t len = 5;

uint32_t net_len = htonl(len);
```

发送：

```
net_len
```

服务端收到之后：

```
uint32_t len = ntohl(net_len);
```

把它转换回来。

你可以先简单记成：

```
htonl()
   ↓
主机 → 网络
```

```
ntohl()
   ↓
网络 → 主机
```

现在不用纠结“大端小端”内部到底怎么排，先把这两个函数记住就行。

## 客户端完整通信部分

你前面的：

```
WSAStartup
socket
connect
```

基本不用改。

主要改通信循环。

```
char buf[1024];

while (1)
{
    printf("请输入要发送的数据: ");

    if (scanf("%1023s", buf) != 1)
        break;

    // =========================
    // 第1步：计算消息长度
    // =========================
    uint32_t len = (uint32_t)strlen(buf);

    // =========================
    // 第2步：主机字节序 -> 网络字节序
    // =========================
    uint32_t net_len = htonl(len);

    // =========================
    // 第3步：先发送4字节的长度
    // =========================
    if (send_exact(fd, (char*)&net_len, sizeof(net_len))
        != sizeof(net_len))
    {
        printf("发送长度失败\n");
        break;
    }

    // =========================
    // 第4步：再发送真正的数据
    // =========================
    if (send_exact(fd, buf, (int)len) != (int)len)
    {
        printf("发送数据失败\n");
        break;
    }

    // =========================
    // 第5步：接收服务器返回的4字节长度
    // =========================
    uint32_t recv_net_len;

    int ret = recv_exact(
        fd,
        (char*)&recv_net_len,
        sizeof(recv_net_len)
    );

    if (ret <= 0)
    {
        printf("服务器断开了连接\n");
        break;
    }

    // 网络字节序 -> 主机字节序
    uint32_t recv_len = ntohl(recv_net_len);

    // 防止服务器发来超过 buf 容量的数据
    if (recv_len >= sizeof(buf))
    {
        printf("收到的数据太大\n");
        break;
    }

    // =========================
    // 第6步：按照长度精确接收数据
    // =========================
    ret = recv_exact(
        fd,
        buf,
        (int)recv_len
    );

    if (ret <= 0)
    {
        printf("接收数据失败\n");
        break;
    }

    // 字符串最后补 '\0'
    buf[recv_len] = '\0';

    printf("收到服务器回复: %s\n", buf);
}
```

你现在服务端的核心问题是：

```

这句的意思其实只是：

> “现在 TCP 缓冲区里有多少，我先拿一些。”

## 服务端核心代码

把你原来的接收循环换成：

```
char buf[BUF_SIZE];

while (1)
{
    // ==================================
    // 第1步：先接收4字节的消息长度
    // ==================================
    uint32_t net_len;

    int ret = recv_exact(
        cfd,
        (char*)&net_len,
        sizeof(net_len)
    );

    if (ret == 0)
    {
        printf("客户端关闭了连接\n");
        break;
    }

    if (ret < 0)
    {
        printf("接收长度失败: %d\n", WSAGetLastError());
        break;
    }

    // ==================================
    // 第2步：网络字节序 -> 主机字节序
    // ==================================
    uint32_t len = ntohl(net_len);

    // ==================================
    // 第3步：防止数据长度超过 buf
    // ==================================
    if (len >= sizeof(buf))
    {
        printf("客户端发送的数据太大\n");
        break;
    }

    // ==================================
    // 第4步：按照长度精确接收消息
    // ==================================
    ret = recv_exact(
        cfd,
        buf,
        (int)len
    );

    if (ret == 0)
    {
        printf("客户端关闭了连接\n");
        break;
    }

    if (ret < 0)
    {
        printf("接收数据失败: %d\n", WSAGetLastError());
        break;
    }

    // ==================================
    // 第5步：补字符串结束符
    // ==================================
    buf[len] = '\0';

    printf("客户端say: %s\n", buf);

    // ==================================
    // 第6步：回显时也要发送
    // [长度][数据]
    // ==================================

    uint32_t send_net_len = htonl(len);

    // 先发4字节长度
    if (send_exact(
            cfd,
            (char*)&send_net_len,
            sizeof(send_net_len))
        != sizeof(send_net_len))
    {
        printf("发送长度失败\n");
        break;
    }

    // 再发数据
    if (send_exact(
            cfd,
            buf,
            (int)len)
        != (int)len)
    {
        printf("发送数据失败\n");
        break;
    }
}
```

# 十四、你原来的 `send_exact()` 又是什么？

同理：

```

```

```

```

```

第二次 send：

```

```
recv_exact()
     ↓
保证“我一直收，直到凑够 n 个字节”
