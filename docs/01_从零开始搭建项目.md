# 01 从零开始搭建项目

## 1. 第一视角：我第一次看到这个项目会懵在哪里

如果我是零基础，我第一次看到：

```cpp
SOCKET fd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
```

很容易产生一个问题：

> `SOCKET` 是什么？`AF_INET` 是什么？`SOCK_STREAM` 又是什么？为什么三个东西都要传？

先不要背。

把它理解成“打电话”：

```text
socket()
   |
   +--> 我要准备一部电话

connect()
   |
   +--> 我要拨给谁

send()
   |
   +--> 我要说什么

recv()
   |
   +--> 对方说了什么

closesocket()
   |
   +--> 挂电话
```

## 2. 为什么 Windows 还要 WSAStartup

Windows 的 Socket API 需要先启动 Winsock 环境：

```cpp
WSADATA wsaData;
WSAStartup(MAKEWORD(2, 2), &wsaData);
```

可以把它想成：

```text
程序
 |
 +--> WSAStartup
       |
       +--> “我要使用 Windows 网络功能”
```

结束时：

```cpp
WSACleanup();
```

就是告诉系统：

> “我不用 Socket 了，可以清理网络环境。”

## 3. 服务器为什么先 listen

服务器不知道客户端什么时候来，所以服务器必须一直等：

```text
socket
  |
bind
  |
listen
  |
accept <--- 客户端 connect
  |
得到 cfd
```

这里非常容易混淆两个 socket：

### lfd

监听 socket。

它的工作是：

> “有没有人来连接？”

### cfd

客户端连接 socket。

它的工作是：

> “已经连接的人，具体和他聊天。”

所以：

```text
lfd = 门卫
cfd = 已经进入房间的客人对应的电话
```

## 4. 客户端为什么不用 listen

因为客户端主动找服务器：

```text
客户端 socket
     |
     +---- connect ----> 服务器 listen
```

所以客户端核心是：

```cpp
connect(fd, ...);
```

服务器核心是：

```cpp
bind()
listen()
accept()
```

## 5. IP 和端口到底是什么

可以先把 IP 理解成“电脑地址”：

```text
172.29.5.195
```

端口理解成“这台电脑上的某个房间”：

```text
IP       = 哪台电脑
PORT     = 哪个程序/服务
```

本项目：

```text
IP   = SERVER_IP
PORT = 8080
```

## 6. 第一次连接测试

服务器启动后应该看到类似：

```text
服务器启动成功，等待客户端连接...
```

客户端连接成功后，服务器应该出现：

```text
客户端 xxx.xxx.xxx.xxx:xxxxx 已连接
```

如果这里失败，不要急着看截图代码。

先检查：

1. 两台机器能不能 ping。
2. IP 是否写对。
3. 8080 是否被防火墙拦截。
4. 服务器是否真的先启动。
5. 两边端口是否都是 8080。

## 7. 第一条学习原则

**先让连接成立，再做协议；先让协议成立，再做截图；先让截图成立，再做输入。**

不要一上来同时改网络、截图、鼠标和键盘。
