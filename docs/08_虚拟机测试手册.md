# 08 虚拟机测试手册

> 这一份是“最后实际测试”的操作手册。当前开发环境没有 Windows 虚拟机，因此不能在这里冒充已经完成 Windows 实机运行测试；拿到项目后按本手册在 Windows 虚拟机执行即可。

## 1. 推荐拓扑

### 方案 A：两台虚拟机

```text
VM-A
服务器 / 被控端
IP：例如 192.168.56.101

        TCP 8080
            <---->

VM-B
客户端 / 控制端
IP：例如 192.168.56.102
```

这是最推荐的测试方式。

### 方案 B：一台虚拟机 + 宿主机

也可以：

```text
虚拟机 = 服务器
宿主机 = 客户端
```

但要注意虚拟网络模式。

## 2. 网络模式

初学者建议先使用：

```text
Host-Only
```

或者使用能够让两台测试机互相访问的局域网模式。

不要一开始就折腾复杂 NAT + 端口映射。

## 3. 第一步：确认 IP

服务器虚拟机：

```bat
ipconfig
```

找到 IPv4，例如：

```text
192.168.56.101
```

然后客户端 `client.cpp`：

```cpp
#define SERVER_IP "192.168.56.101"
```

## 4. 第二步：先 ping

客户端执行：

```bat
ping 192.168.56.101
```

必须先做到：

```text
能 ping
```

如果 ping 不通，不要启动远程控制程序继续排查。

## 5. 第三步：服务器先启动

运行服务器。

应该看到：

```text
服务器启动成功，等待客户端连接...
```

## 6. 第四步：客户端启动

客户端连接后，服务器应看到类似：

```text
客户端 192.168.56.xxx:xxxxx 已连接
```

## 7. 第五步：画面测试

观察客户端窗口：

```text
是否显示服务器桌面
```

如果黑屏：

```text
先检查 HandleScreen
再检查 JPEG
再检查 chunk
最后检查 DisplayFrame
```

## 8. 第六步：鼠标移动

测试：

```text
慢慢移动
快速移动
画圈
移动到窗口边缘
拖动窗口外再回来
```

重点观察：

```text
光标是否跳飞
是否延迟明显
是否卡顿
```

## 9. 第七步：鼠标按键

依次测试：

```text
左键单击
右键单击
中键单击
左键双击
右键双击
中键双击
滚轮向上
滚轮向下
```

## 10. 第八步：键盘

测试：

```text
A
Z
1
9
Enter
Backspace
Space
方向键
```

然后测试：

```text
左 Shift + A
右 Shift + A
左 Shift + 1
右 Shift + 1
```

## 11. 第九步：重点测试 Shift

测试表：

| 测试 | 预期 |
|---|---|
| 左 Shift 按下 | 服务端保持左 Shift down |
| 左 Shift 松开 | 服务端收到左 Shift up |
| 右 Shift 按下 | 服务端保持右 Shift down |
| 右 Shift 松开 | 服务端收到右 Shift up |
| Shift+A | 得到大写 A 行为 |
| Shift+数字 | 得到对应组合键行为 |

## 12. 第十步：测试鼠标频率

代码当前：

```cpp
#define MOUSE_MOVE_INTERVAL_MS 10
```

理论目标：

```text
约 100 次/秒
```

如果明显卡顿，可以尝试：

```text
16ms -> 约 60Hz
10ms -> 约 100Hz
8ms  -> 约 125Hz
4ms  -> 约 250Hz
```

初学者不要一开始就改成 1ms。

## 13. 第十一步：测试断开

关闭客户端窗口。

服务器不能崩溃。

然后：

```text
重新启动服务器
重新启动客户端
```

确认能够再次连接。

## 14. 第十二步：测试防火墙

如果：

```text
ping 通
但 TCP 8080 不通
```

检查 Windows Defender 防火墙入站规则。

可以临时为实验环境建立 TCP 8080 入站允许规则。

不要为了测试长期关闭整台机器的防火墙。

## 16. 出现问题时怎么记录

不要只写：

```text
不能用
```

要记录：

```text
时间：
客户端 IP：
服务器 IP：
服务器是否启动：
是否 ping 通：
是否连接成功：
最后看到的日志：
具体哪个功能失败：
```

这样才能定位问题。
